# Contributing Guidelines

This repository represents completed academic coursework for the University of California San Diego's Algorithms on Graphs course.

---

## Academic Integrity Policy

* **No Solution Alterations**: In observance of academic integrity and institutional honor codes, pull requests altering canonical assignment solutions will be declined to prevent providing answers to actively enrolled students.
* **Permitted Contributions**: Contributions are strictly limited to documentation enhancements, asymptotic complexity clarifications, and test case additions.

---

## Code of Conduct

All contributors and participants must adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).

---

## Pull Request Guidelines

1. Confirm that changes preserve academic integrity and do not alter graded solutions.
2. Ensure no personal credentials or proprietary course problem statements are committed.
3. Open a Pull Request targeting the `main` branch and complete the academic checklist.
